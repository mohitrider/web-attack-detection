# Dataset Instructions

## Dataset Source

This project uses the CSE-CIC-IDS2018 dataset:

https://registry.opendata.aws/cse-cic-ids2018/

The original dataset is not included in this repository.

## Required Files

Download these two CICFlowMeter CSV files:

1. Thursday-22-02-2018_TrafficForML_CICFlowMeter.csv
2. Friday-23-02-2018_TrafficForML_CICFlowMeter.csv

## Required Directory Structure

Place both files inside `data/raw/`:

    data/
    └── raw/
        ├── Thursday-22-02-2018_TrafficForML_CICFlowMeter.csv
        └── Friday-23-02-2018_TrafficForML_CICFlowMeter.csv

## Data Handling

Raw and processed datasets are excluded from this GitHub repository. Users must obtain the data from the original source and follow its applicable access and usage terms.
